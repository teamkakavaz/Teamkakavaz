========================

This is a complete responsive static storefront concept.
To publish free:
1. Create a GitHub account.
2. Create a new public repository.
3. Upload these three files.
4. Enable GitHub Pages in Settings > Pages.
5. Your free site will get a github.io address.
6. Later, connect teamkakavaz.pk if you buy the domain and choose a host/plan that supports custom domains.
